Acerca de este proyecto

Un esfuerzo personal e independiente para acercar Protocols a lectores y oyentes hispanohablantes.

Cómo se hizo

Todo el material se generó de forma automatizada a partir de una copia personal del libro.

Captura del Kindle

Se tomaron las páginas del libro desde un lector Kindle personal para obtener imágenes de cada página.

OCR

Las imágenes se pasaron por reconocimiento óptico de caracteres para recuperar el texto original en inglés.

Traducción asistida por IA

El texto en inglés se tradujo al español con modelos de lenguaje, capítulo por capítulo.

Naturalización del texto

Una revisión adicional pulió la traducción para que suene natural y fluida, no literal.

Voz sintética (TTS)

El texto en español se narra con voz sintética de ElevenLabs para crear el audiolibro, con transcripciones sincronizadas.
